Privacy Policy

ThatSpookyFact Production · Effective 17 September 2026

This policy explains how the ThatSpookyFact Production app ("the app") accesses, uses, stores and shares Google user data. The app is a private tool operated by the owner of the That Spooky Fact YouTube channel for that channel only. It is not offered to the public; the only Google accounts that sign in to it are the channel owner's own accounts.

Google user data the app accesses

  • Google Drive — files in the owner's own ThatSpookyFact Drive folders: production records, state files, and finished videos with their descriptions.
  • YouTube Analytics (read-only) — performance figures for the owner's own channel and its videos, such as views, watch time, average view duration, likes, comments, shares, subscriber changes and traffic sources. YouTube provides these as aggregate totals; they do not identify individual viewers.

The app does not access Gmail, contacts, calendars, or any other person's Google account.

How the data is used

  • Drive access is used to read and update the channel's production files and to deliver finished videos to the owner's review folder.
  • YouTube Analytics data is used to produce a weekly report on how the channel's videos are performing, so the owner can decide what to try next.

The app never publishes, edits, or deletes YouTube content, and the data is not used for advertising.

Storage and security

Data the app works with is stored in the owner's own Google Drive and Google Cloud project. Access credentials are kept in Google Cloud Secret Manager and are never published. Processing runs in temporary Google Cloud containers that are deleted after each run.

Sharing

Google user data is not sold, rented, or shared for advertising. The only transfer to a third party is this: aggregate channel performance figures (numbers such as view counts and averages, with no personal information) are sent to the DeepSeek API to help write the weekly report's commentary. No Drive files and no account credentials are sent to it. Otherwise data is shared only if required by law.

Limited Use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is not used to develop, improve, or train generalized AI or machine-learning models.

Retention and deletion

Data is kept in the owner's Drive and Cloud project for as long as the owner needs it for the channel, and can be deleted by the owner at any time. Access can be withdrawn at any time from the Google Account's third-party access settings.

Changes

If this policy changes, the updated version will be posted on this page with a new effective date.
